# LOOM 交付与验证记录

## 实现范围

本次交付纯本地 CLI + Web 控制台，不使用 Manus 托管、不上传代码、不公开发布。宿主支持本地目录预检、摘要与信任确认、安装快照、清单查看、Schema 配置、权限授权、启用/禁用、卸载、动态工具运行及结果事件。Agent 支持真实 Ollama 与兼容 OpenAI HTTP，有界执行、取消和逐次写入批准。

工作区检索和本地笔记分别位于独立插件目录。前者从明确授权的文本工作区返回路径、行号与实际内容；后者将笔记保存到按插件隔离的私有存储。宿主没有这两个业务的固定分支。第三方扩展测试另外生成一个反转文本插件，在不改宿主的情况下安装、运行并获得结果。

## 时间、优先级与范围控制

实现从 2026-11-11 14:37 开始，本机时间约 15:10 完成主要实现与定点验证。先完成协议和通用核心，再并行实现控制台与独立插件；模型适配、验证与文档由主任务整合。同步等待包含前端实际冒烟和只读验收，而不是宣称全部时间均是编码时间。

P0 的插件生命周期、真实不同插件与模型工具调用机制已完成。P1 的 Schema 表单、写入确认、取消、历史和模型测试也已完成。P2 的在线市场、远程安装、自动更新、OS 沙箱、桌面打包、多用户认证和系统自启动不在本次范围，不用占位按钮伪装成已完成。

## AI 使用与审查

主任务负责协议和边界、宿主核心、CLI/HTTP、模型循环、集成测试、交付整合。两个并行代理分别负责前端与独立插件，修改目录互不冲突。一个只读代理追踪 CLI/Web → Harness → 通用 worker/broker → 插件与模型连接，不修改业务源码。

审查和实测发现并修复：控制台焦点保护导致安装或启用后卡片状态不刷新；新运行可能短暂显示旧成功结果；高级 JSON 切换可能覆盖内容；第三方必填配置缺默认值时不能先安装；取消时延迟 broker 写入可能晚于卸载提交；150 条日志上限可能吞掉批准请求。每项均针对真实时序或代码路径处理，没有只接受 AI 生成结果。

后两项修复增加了写锁内授权与取消复查、broker 收尾闸门、卸载等待运行锁，以及保留批准/终态的有界事件轨迹。相关定点测试证明不会在卸载后重新创建存储，也不会因日志已满隐藏批准 callId。

## 已知限制与下一步

当前电脑未发现 Ollama 可执行程序，没有用于本次测试的真实模型凭据，**未完成真实 LLM 的可用性和回答质量验证**。准备支持工具调用的模型后，应在模型设置中填写实际服务和模型名，测试连接再执行端到端 Agent 任务。服务不能连通时如实失败，不内置假 AI 回复。

插件不是 OS 沙箱；恶意代码可以绕过 broker，本次只面向已审查可信插件。笔记与配置是本机明文，依赖系统权限及磁盘保护。卸载删除插件数据，不提供无损升级；取消不保证回滚已经提交的写入。v1 不支持跨机器并发、在线签名信任、自动依赖安装或幂等笔记新增。

下一步优先是接入用户实际的本机模型并验证工具调用质量，再根据真实需求考虑导出/备份笔记、无损插件升级或更强隔离，而不是扩充未经验证的市场功能。
